How a lesson works

  1. PlayMove the sliders and press play. See the idea before the formula.
  2. ReadShort explanations in the textbook's words, with the equations.
  3. TryButtons set up the simulation for each worked example so you can check the answer.
  4. CheckA four-question quiz, then download the slides for class.
