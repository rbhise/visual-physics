Frequency Tables and Cumulative Frequency

Thirty test marks written in a row tell you very little. Sort them into a table and you can see at once how many students did well, how many struggled and where most of them lie.

Data

Numerical information collected for a study is called data. Data collected by the investigator himself or herself, for example by asking each student in the class, is primary data. Data taken from records already collected by someone else, such as a school register or a government report, is secondary data.

Data in the form in which it was collected, not yet arranged in any way, is raw data.

Tally marks and frequency

The number of times an observation occurs is its frequency. To count quickly, draw a tally mark for each observation: four vertical strokes, and the fifth drawn across them, so the marks come in easy bundles of five.

A table showing each observation with its frequency is an ungrouped frequency distribution table. The sum of all the frequencies is the number of observations, written \(N\).

Grouped frequency tables

When the observations are spread over a wide range, group them into classes such as 10–20, 20–30, … . In the class 20–30, 20 is the lower class limit and 30 is the upper class limit; the difference, 10, is the class width.

Class mark \(= \dfrac{\text{lower class limit} + \text{upper class limit}}{2}\). For 20–30 the class mark is \(\dfrac{20 + 30}{2} = 25\).
  • Exclusive classes (10–20, 20–30, …): the upper limit is not included. An observation of 20 goes into 20–30.
  • Inclusive classes (10–19, 20–29, …): both limits are included. To make them continuous, subtract 0.5 from each lower limit and add 0.5 to each upper limit: 9.5–19.5, 19.5–29.5, … .

Cumulative frequency

The cumulative frequency (c.f.) of a class is a running total of frequencies.

  • Less than type: add each frequency to the total of the classes above it. It counts the observations less than the upper limit of that class. The last one equals \(N\).
  • More than type: start from the last class and add upwards. It counts the observations equal to or more than the lower limit of that class. The first one equals \(N\).

Try it

Choose a table, then press “Sort the data” to watch each value find its row. Tap a row to read it.

  • Ungrouped. Family sizes of 25 students.
  • Grouped. 30 test marks in classes of width 10.
  • Narrower classes. The same marks, width 5.
  • Inclusive. Classes 10–19, 20–29, …
  • Less than c.f. Running totals going down.
  • More than c.f. Running totals going up.

What you should see: 8 of the 25 families have 4 members. With width 10 the frequencies are 5, 8, 11 and 6; with width 5 the class 30–35 is the fullest, with 6. The marks 20 and 30 go into 20–30 and 30–40, never into the class they end. The less-than c.f. column reads 5, 13, 24, 30; the more-than column reads 30, 25, 17, 6.

Worked examples

1. An ungrouped table

The family sizes of 25 students are: 4, 3, 5, 4, 6, 2, 4, 3, 5, 7, 4, 3, 4, 5, 6, 3, 4, 2, 5, 4, 3, 6, 4, 5, 3. Make a frequency table.

  1. The values run from 2 to 7. Draw one tally mark for each student in the row of his or her family size.
  2. Frequencies: 2 → 2, 3 → 6, 4 → 8, 5 → 5, 6 → 3, 7 → 1.
  3. Check: \(2 + 6 + 8 + 5 + 3 + 1 = 25 = N\) ✓ 8 families have 4 members, the most common size

2. A grouped table

Make a grouped frequency table of the 30 marks shown in the simulation, with exclusive classes 10–20, 20–30, 30–40, 40–50. Give the class marks.

  1. Put each mark in its class; a mark of 20 goes into 20–30 and a mark of 30 into 30–40.
  2. Frequencies: 5, 8, 11, 6. Check: \(5 + 8 + 11 + 6 = 30\) ✓
  3. Class marks: \(\tfrac{10 + 20}{2} = 15\), then 25, 35, 45. f = 5, 8, 11, 6; class marks 15, 25, 35, 45

3. Cumulative frequency

From the table in Example 2, how many students scored less than 30? How many scored 30 or more?

  1. Less than c.f.: 5, \(5 + 8 = 13\), \(13 + 11 = 24\), \(24 + 6 = 30\). The class 20–30 has c.f. 13.
  2. More than c.f., from the bottom: 6, \(6 + 11 = 17\), \(17 + 8 = 25\), \(25 + 5 = 30\). The class 30–40 has c.f. 17.
  3. 13 students scored less than 30; 17 scored 30 or more. Check: \(13 + 17 = 30\) ✓

Common mistakes

  • Counting a boundary value twice. In exclusive classes 20 belongs only to 20–30. In inclusive classes the next class starts at 20.
  • Class mark as the width. The class mark is the middle of the class, (lower + upper) ÷ 2, not upper − lower.
  • Frequencies that do not add up to N. Always total the frequency column; if it is not N, a value was missed or counted twice.
  • More-than c.f. added downwards. Start at the last class and add upwards; the first entry should equal N.

Quick check

1. What is the class mark of the class 40–50?

(40 + 50) ÷ 2 = 45.

2. With exclusive classes 10–20, 20–30, 30–40, the observation 30 is counted in…

The upper limit is not included in an exclusive class, so 30 belongs to 30–40.

3. Four classes have frequencies 4, 7, 9 and 5. What is the less-than cumulative frequency of the third class?

4 + 7 + 9 = 20.

4. A student asks every classmate how they travel to school. This is…

The student collected the data directly, so it is primary data.
