Polynomials, lesson 2

Operations and Synthetic Division

Polynomials add, subtract and multiply much like numbers do: line up the like terms. Dividing by x − a has a shortcut, synthetic division, that needs only the coefficients.

Adding and subtracting

Add or subtract the coefficients of like terms (terms with the same power of \(x\)). Writing the polynomials one under the other, in standard form, keeps like terms in the same column.

$$\begin{aligned} (2x^2 - 3x + 1) + (x^2 + 2x - 4) &= 3x^2 - x - 3 \\ (2x^2 - 3x + 1) - (x^2 + 2x - 4) &= 2x^2 - 3x + 1 - x^2 - 2x + 4 = x^2 - 5x + 5 \end{aligned}$$

To subtract, change the sign of every term of the second polynomial and then add.

Multiplying

Multiply every term of the first polynomial by every term of the second, then collect like terms. Use \(x^m \times x^n = x^{m+n}\).

$$(x + 2)(x^2 - 3x + 1) = x^3 - 3x^2 + x + 2x^2 - 6x + 2 = x^3 - x^2 - 5x + 2$$

The degree of a product is the sum of the degrees: here \(1 + 2 = 3\).

Dividing: the division algorithm

Division algorithm. If \(p(x)\) and \(s(x)\) are two polynomials and the degree of \(p(x)\) is greater than or equal to the degree of \(s(x)\), then on dividing \(p(x)\) by \(s(x)\) we get a quotient \(q(x)\) and a remainder \(r(x)\) such that
\(p(x) = s(x) \times q(x) + r(x)\), that is, Dividend = Divisor × Quotient + Remainder,
where \(r(x) = 0\) or the degree of \(r(x)\) is less than the degree of \(s(x)\).

Long division works like long division of numbers: divide the first terms, multiply back, subtract, bring down the next term, and repeat.

Synthetic division

When the divisor is \(x - a\), there is a quicker method that uses only coefficients.

  1. Write the dividend in standard form and list its coefficients, writing 0 for any missing power. Write \(a\) on the left. (For \(x + 3\), \(a = -3\).)
  2. Bring down the first coefficient.
  3. Multiply it by \(a\) and write the product under the next coefficient. Add.
  4. Repeat “multiply by \(a\), then add” to the end. The last number is the remainder; the others are the coefficients of the quotient, whose degree is one less than the dividend's.

For \((x^3 - 6x^2 + 11x - 6) \div (x - 2)\): coefficients \(1, -6, 11, -6\) and \(a = 2\) give \(1,\ -4,\ 3\) and remainder 0. So the quotient is \(x^2 - 4x + 3\) and \(x^3 - 6x^2 + 11x - 6 = (x - 2)(x^2 - 4x + 3) + 0\).

Try it

Choose an operation. For synthetic division, press “Divide step by step” and watch each cell fill.

  • Divide by x − 2. x³ − 6x² + 11x − 6.
  • Divide by x + 2. 2x³ − 5x + 7 has no x² term.
  • Degree 4. x⁴ − 16 divided by x − 2.
  • Add. (2x² − 3x + 1) + (x² + 2x − 4).
  • Subtract. The same pair, subtracted.
  • Multiply. (x + 2)(x² − 3x + 1).

What you should see: x³ − 6x² + 11x − 6 ÷ (x − 2) gives quotient x² − 4x + 3, remainder 0. For 2x³ − 5x + 7 use the coefficients 2, 0, −5, 7 and a = −2: quotient 2x² − 4x + 3, remainder 1. x⁴ − 16 ÷ (x − 2) gives x³ + 2x² + 4x + 8, remainder 0. The sum is 3x² − x − 3, the difference x² − 5x + 5, and the product x³ − x² − 5x + 2.

Worked examples

1. Subtraction

Subtract \(3x^2 + 4x - 1\) from \(5x^2 - 2x + 6\).

  1. \((5x^2 - 2x + 6) - (3x^2 + 4x - 1) = 5x^2 - 2x + 6 - 3x^2 - 4x + 1\)
  2. Collect like terms: \((5 - 3)x^2 + (-2 - 4)x + (6 + 1)\)
  3. \(2x^2 - 6x + 7\)

2. Multiplication

Multiply \((2x - 3)(x^2 + x - 2)\).

  1. \(2x(x^2 + x - 2) = 2x^3 + 2x^2 - 4x\)
  2. \(-3(x^2 + x - 2) = -3x^2 - 3x + 6\)
  3. Add: \(2x^3 - x^2 - 7x + 6\) (degree 1 + 2 = 3)

3. Synthetic division by x + 3

Divide \(x^3 + 2x^2 - 5x - 4\) by \(x + 3\) and write the answer as Dividend = Divisor × Quotient + Remainder.

  1. \(x + 3 = x - (-3)\), so \(a = -3\). Coefficients: \(1, 2, -5, -4\).
  2. Bring down 1. \(1 \times (-3) = -3\), \(2 - 3 = -1\). \(-1 \times (-3) = 3\), \(-5 + 3 = -2\). \(-2 \times (-3) = 6\), \(-4 + 6 = 2\).
  3. Quotient \(x^2 - x - 2\), remainder 2.
  4. \(x^3 + 2x^2 - 5x - 4 = (x + 3)(x^2 - x - 2) + 2\)

Common mistakes

  • Skipping a missing power. In 2x³ − 5x + 7 there is no x² term. Write its coefficient as 0: 2, 0, −5, 7.
  • Using +3 for x + 3. Synthetic division needs x − a. Since x + 3 = x − (−3), use a = −3.
  • Changing only the first sign. −(x² + 2x − 4) = −x² − 2x + 4. Every term of the subtracted polynomial changes sign.
  • Multiplying the degrees. The degree of a product is the sum of the degrees: (x² + 1)(x³ − 2) has degree 5.

Quick check

1. \((3x^2 + x - 2) + (x^2 - 4x + 5) = \)…

x² terms: 3 + 1 = 4; x terms: 1 − 4 = −3; numbers: −2 + 5 = 3.

2. The degree of \((x^2 + 1)(x^3 - 2)\) is…

x² × x³ = x⁵: add the degrees, 2 + 3 = 5.

3. To divide by \(x + 4\) using synthetic division, the number written on the left is…

x + 4 = x − (−4), so a = −4.

4. Dividing \(p(x)\) by \(x - 1\) gives quotient \(x^2 + 2\) and remainder 3. Then \(p(x) = \)…

(x − 1)(x² + 2) + 3 = x³ − x² + 2x − 2 + 3 = x³ − x² + 2x + 1.
