Remainder and Factor Theorems

Divide p(x) by x − a and the remainder is simply p(a). When that remainder is 0, the graph meets the x-axis at a, and x − a is a factor. That one idea lets you factorise cubics.

The remainder theorem

Remainder theorem. If the polynomial \(p(x)\) is divided by \((x - a)\), the remainder is \(p(a)\).

Why: by the division algorithm, \(p(x) = (x - a) \times q(x) + r\), where \(r\) is a number (its degree is less than 1). Put \(x = a\): \(p(a) = 0 \times q(a) + r = r\).

So you can find the remainder without dividing. Dividing \(p(x) = x^3 - 4x^2 + x + 6\) by \(x - 1\) leaves \(p(1) = 1 - 4 + 1 + 6 = 4\). For a divisor \(x + a\), use \(p(-a)\). On the graph, the remainder is the height of the curve above \(x = a\).

Zeroes of a polynomial

If \(p(a) = 0\), then \(a\) is called a zero of the polynomial \(p(x)\). At a zero, the graph of \(p(x)\) meets the x-axis. For \(x^3 - 4x^2 + x + 6\), \(p(2) = 8 - 16 + 2 + 6 = 0\), so 2 is a zero.

The factor theorem

Factor theorem. If \(p(x)\) is a polynomial and \(p(a) = 0\), then \((x - a)\) is a factor of \(p(x)\). Conversely, if \((x - a)\) is a factor of \(p(x)\), then \(p(a) = 0\).

It follows from the remainder theorem: \(p(a) = 0\) means the remainder is 0, so \(x - a\) divides \(p(x)\) exactly.

Factorising a cubic

  1. Try small divisors of the constant term, \(\pm 1, \pm 2, \ldots\), until \(p(a) = 0\). (With leading coefficient 1, any integer zero must divide the constant term.)
  2. Divide by \(x - a\) with synthetic division. The quotient is a quadratic.
  3. Factorise the quadratic by splitting the middle term.

For \(x^3 - x^2 - 10x - 8\): \(p(1) = -18\), but \(p(-1) = 0\), so \(x + 1\) is a factor. Dividing gives \(x^2 - 2x - 8 = (x - 4)(x + 2)\). So \(x^3 - x^2 - 10x - 8 = (x + 1)(x + 2)(x - 4)\).

Try it

Set p(x) and a, or press “Find a factor” to try the divisors of the constant term one by one.

  • Remainder. x³ − 4x² + x + 6 divided by x − 1.
  • A zero. The same p(x), divided by x − 2.
  • Divide by x + 2. 2x³ + 3x² − x + 5.
  • Find a factor. x³ − x² − 10x − 8.

What you should see: Dividing x³ − 4x² + x + 6 by x − 1 leaves 4, and p(1) = 4: the point (1, 4) is on the graph. With a = 2 the remainder is 0: the graph meets the x-axis at 2, and x − 2 is a factor. For 2x³ + 3x² − x + 5 and x + 2, p(−2) = −16 + 12 + 2 + 5 = 3. For x³ − x² − 10x − 8, a = 1 gives remainder −18, then a = −1 gives 0, so x + 1 is a factor and p(x) = (x + 1)(x + 2)(x − 4).

Worked examples

1. Remainder without dividing

Find the remainder when \(x^4 - 3x^2 + 2x + 5\) is divided by \(x - 1\).

  1. By the remainder theorem, the remainder is \(p(1)\).
  2. \(p(1) = 1 - 3 + 2 + 5 = \) 5

2. Finding an unknown coefficient

If \(x - 2\) is a factor of \(x^3 + kx^2 - 4x - 8\), find \(k\).

  1. By the factor theorem, \(p(2) = 0\).
  2. \(8 + 4k - 8 - 8 = 0\), so \(4k = 8\).
  3. k = 2

3. Factorising a cubic

Factorise \(x^3 - 2x^2 - 5x + 6\).

  1. Try \(a = 1\): \(p(1) = 1 - 2 - 5 + 6 = 0\). So \(x - 1\) is a factor.
  2. Synthetic division by \(x - 1\): coefficients \(1, -2, -5, 6\) give \(1, -1, -6\) and remainder 0. Quotient \(x^2 - x - 6\).
  3. \(x^2 - x - 6 = x^2 - 3x + 2x - 6 = (x - 3)(x + 2)\).
  4. \((x - 1)(x + 2)(x - 3)\)

Common mistakes

  • Using the wrong sign. For the divisor x + 2, find p(−2), not p(2). x + 2 = x − (−2).
  • Expecting the quotient from p(a). The remainder theorem gives only the remainder. For the quotient, divide.
  • Stopping at one factor. After finding x − a, divide and factorise the quadratic quotient too.
  • Guessing at random. Try divisors of the constant term: ±1, ±2, ±3, … Other integers cannot be zeroes.

Quick check

1. The remainder when \(x^3 + 2x - 1\) is divided by \(x - 1\) is…

p(1) = 1 + 2 − 1 = 2.

2. \(x - 3\) is a factor of \(p(x)\) when…

Factor theorem: x − a is a factor exactly when p(a) = 0, here a = 3.

3. The remainder when \(x^2 + 5x + 7\) is divided by \(x + 2\) is…

p(−2) = 4 − 10 + 7 = 1.

4. Which is a factor of \(x^3 - 7x + 6\)?

p(1) = 1 − 7 + 6 = 0. The others give p(−1) = 12, p(−2) = 12, p(3) = 12.
