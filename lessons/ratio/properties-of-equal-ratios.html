Ratio and Proportion, lesson 2

Properties of Equal Ratios

If two ratios are equal, you can turn them upside down, swap their terms, or add the bottom to the top, and they stay equal. These moves have names, and they make many problems short.

Five properties

Let \(a, b, c, d\) be positive numbers with \(\dfrac{a}{b} = \dfrac{c}{d}\). For example \(\dfrac{6}{8} = \dfrac{9}{12}\), since both equal \(\dfrac{3}{4}\). Then:

PropertyIf \(\frac{a}{b} = \frac{c}{d}\), then…With 6/8 = 9/12
Invertendo\(\dfrac{b}{a} = \dfrac{d}{c}\)\(\frac{8}{6} = \frac{12}{9} = \frac{4}{3}\)
Alternando\(\dfrac{a}{c} = \dfrac{b}{d}\)\(\frac{6}{9} = \frac{8}{12} = \frac{2}{3}\)
Componendo\(\dfrac{a + b}{b} = \dfrac{c + d}{d}\)\(\frac{14}{8} = \frac{21}{12} = \frac{7}{4}\)
Dividendo\(\dfrac{a - b}{b} = \dfrac{c - d}{d}\)\(\frac{-2}{8} = \frac{-3}{12} = -\frac{1}{4}\)
Componendo-dividendo\(\dfrac{a + b}{a - b} = \dfrac{c + d}{c - d}\), if \(a \ne b,\; c \ne d\)\(\frac{14}{-2} = \frac{21}{-3} = -7\)

Why they work

Invertendo: divide 1 by both equal numbers. Alternando: \(\frac{a}{b} = \frac{c}{d}\) means \(ad = bc\); divide both sides by \(cd\) to get \(\frac{a}{c} = \frac{b}{d}\). Componendo: add 1 to both sides: \(\frac{a}{b} + 1 = \frac{c}{d} + 1\), that is \(\frac{a + b}{b} = \frac{c + d}{d}\). Dividendo: subtract 1 from both sides. Componendo-dividendo: divide the componendo result by the dividendo result.

Remember. Do the same thing to both ratios. And never use componendo-dividendo when \(a = b\): then \(a - b = 0\), and we cannot divide by 0.

Using the properties

Componendo-dividendo is very handy when an equation has the form \(\dfrac{\text{something} + \text{something}}{\text{something} - \text{something}}\). Applying it makes the sums and differences collapse, as in Example 3 below.

Try it

Pick a property, then press “Show the step”. The sliders change the numbers: a = p × m, b = q × m, c = p × n, d = q × n.

  • Invertendo. 6/8 = 9/12 turned upside down.
  • Alternando. Swap b and c in 6/8 = 9/12.
  • Componendo. Add each denominator to its numerator.
  • Dividendo. 10/4 = 15/6: take the denominator away.
  • Componendo-dividendo. 10/4 = 15/6 again.

What you should see: 8/6 = 12/9 = 4/3; 6/9 = 8/12 = 2/3; 14/8 = 21/12 = 7/4. For 10/4 = 15/6, dividendo gives 6/4 = 9/6 = 3/2 and componendo-dividendo gives 14/6 = 21/9 = 7/3.

Worked examples

1. Componendo and dividendo

If \(\dfrac{a}{b} = \dfrac{5}{3}\), find \(\dfrac{a + b}{b}\) and \(\dfrac{a - b}{b}\).

  1. Componendo: \(\dfrac{a + b}{b} = \dfrac{5 + 3}{3} = \) 8/3
  2. Dividendo: \(\dfrac{a - b}{b} = \dfrac{5 - 3}{3} = \) 2/3

2. Make a new ratio first

If \(\dfrac{a}{b} = \dfrac{7}{4}\), find \(\dfrac{5a + 4b}{5a - 4b}\).

  1. Multiply: \(\dfrac{5a}{4b} = \dfrac{5 \times 7}{4 \times 4} = \dfrac{35}{16}\).
  2. Componendo-dividendo: \(\dfrac{5a + 4b}{5a - 4b} = \dfrac{35 + 16}{35 - 16} = \) 51/19

3. Solving an equation

Solve \(\dfrac{x + 4}{x - 4} = \dfrac{5}{3}\).

  1. Componendo-dividendo: \(\dfrac{(x + 4) + (x - 4)}{(x + 4) - (x - 4)} = \dfrac{5 + 3}{5 - 3}\).
  2. \(\dfrac{2x}{8} = \dfrac{8}{2} = 4\), so \(2x = 32\) and x = 16
  3. Check: \(\dfrac{20}{12} = \dfrac{5}{3}\) ✓. In the simulation, 20/12 = 5/3 gives \(\frac{32}{8} = \frac{8}{2} = 4\) on both sides.

Common mistakes

  • Changing one side only. Each property changes both ratios in the same way. Add b on the left, add d on the right.
  • Alternando the wrong way. From a/b = c/d, alternando gives a/c = b/d: first terms together, second terms together.
  • Dividing by zero. Componendo-dividendo needs a ≠ b. If a = b, then a − b = 0.
  • Mixed-up differences. Use a − b on the left and c − d on the right, in the same order on both sides.

Quick check

1. If a/b = 3/5, invertendo gives b/a = …

Invertendo turns both ratios upside down.

2. If a/b = 4/3, then (a + b)/b is…

Componendo: (4 + 3)/3 = 7/3.

3. If x/y = 9/5, then (x + y)/(x − y) is…

Componendo-dividendo: (9 + 5)/(9 − 5) = 14/4 = 7/2.

4. Which property turns a/b = c/d into a/c = b/d?

Alternando swaps the means b and c.
