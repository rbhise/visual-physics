Theorem on Equal Ratios and the k Method

Three bags of mixed nuts each hold almonds and cashews in the ratio 2 : 3. Tip them all into one bowl: the ratio in the bowl is still 2 : 3. That is the theorem on equal ratios.

Theorem on equal ratios

Theorem. If \(\dfrac{a}{b} = \dfrac{c}{d} = \dfrac{e}{f} = \cdots\), then each ratio is equal to $$\frac{a + c + e + \cdots}{b + d + f + \cdots}$$ More generally, for numbers \(l, m, n, \ldots\) with \(lb + md + nf + \cdots \ne 0\), each ratio is equal to $$\frac{la + mc + ne + \cdots}{lb + md + nf + \cdots}$$

For example \(\dfrac{6}{9} = \dfrac{4}{6} = \dfrac{10}{15}\) (each is \(\frac{2}{3}\)), and \(\dfrac{6 + 4 + 10}{9 + 6 + 15} = \dfrac{20}{30} = \dfrac{2}{3}\) as well.

The k method

To prove the theorem, call the common value of the ratios \(k\):

$$\frac{a}{b} = \frac{c}{d} = \frac{e}{f} = k \quad\Rightarrow\quad a = bk,\; c = dk,\; e = fk$$

Then \(\dfrac{la + mc + ne}{lb + md + nf} = \dfrac{lbk + mdk + nfk}{lb + md + nf} = \dfrac{k(lb + md + nf)}{lb + md + nf} = k\). Every piece of the top is \(k\) times the matching piece of the bottom, so the whole top is \(k\) times the whole bottom. This way of working is called the k method. It is the easiest way to prove many statements about equal ratios: replace each numerator by (denominator × \(k\)) and simplify both sides.

Continued proportion

Continued proportion. If \(\dfrac{a}{b} = \dfrac{b}{c}\), then \(a, b, c\) are in continued proportion. Then \(b^2 = ac\), and \(b\) is called the mean proportional of \(a\) and \(c\): \(b = \sqrt{ac}\).

For example \(4, 6, 9\) are in continued proportion: \(\frac{4}{6} = \frac{6}{9} = \frac{2}{3}\) and \(6^2 = 36 = 4 \times 9\). In the simulation, a rectangle \(a \times c\) and a square \(b \times b\) have the same area. With the k method, \(\frac{a}{b} = \frac{b}{c} = k\) gives \(b = ck\) and \(a = bk = ck^2\).

Try it

In the theorem view, press “Combine” to slide the pieces into one big ratio. The other view shows continued proportion.

  • With l, m, n. Take 2 copies of 6/9, 1 of 4/6 and 3 of 10/15.
  • Mean proportional. a = 4 and c = 9.
  • Not a whole number. a = 3 and c = 5.

What you should see: 20/30 = 2/3. With l = 2, m = 1, n = 3: (12 + 4 + 30)/(18 + 6 + 45) = 46/69 = 2/3. For 4 and 9 the mean proportional is 6; for 3 and 5 it is √15 ≈ 3.87.

Worked examples

1. Using the theorem

Verify the theorem for \(\dfrac{4}{6} = \dfrac{6}{9} = \dfrac{10}{15}\) with \(l = 2,\; m = 1,\; n = 3\).

  1. Each ratio is \(\frac{2}{3}\).
  2. \(\dfrac{2(4) + 1(6) + 3(10)}{2(6) + 1(9) + 3(15)} = \dfrac{8 + 6 + 30}{12 + 9 + 45} = \dfrac{44}{66} = \) 2/3 ✓

2. Proving an identity by the k method

If \(\dfrac{a}{b} = \dfrac{c}{d}\), show that \(\dfrac{a^2 + c^2}{b^2 + d^2} = \dfrac{ac}{bd}\).

  1. Let \(\frac{a}{b} = \frac{c}{d} = k\), so \(a = bk\) and \(c = dk\).
  2. Left side: \(\dfrac{b^2k^2 + d^2k^2}{b^2 + d^2} = \dfrac{k^2(b^2 + d^2)}{b^2 + d^2} = k^2\).
  3. Right side: \(\dfrac{bk \cdot dk}{bd} = k^2\). Both sides equal \(k^2\): proved

3. Mean proportional

Find the mean proportional of 8 and 18.

  1. If \(8, b, 18\) are in continued proportion, \(b^2 = 8 \times 18 = 144\).
  2. \(b = \sqrt{144} = \) 12. Check: \(\frac{8}{12} = \frac{12}{18} = \frac{2}{3}\) ✓

Common mistakes

  • Adding any two fractions this way. 1/2 + 1/3 is not 2/5. Adding tops and bottoms works only to find a ratio equal to ratios that are already equal.
  • Writing a = k/b. From a/b = k, multiply: a = bk.
  • Forgetting the zero check. The combined denominator lb + md + nf must not be 0.
  • Averaging for the mean proportional. The mean proportional of 4 and 9 is √36 = 6, not (4 + 9)/2.

Quick check

1. If a/b = c/d = 2/5, then (a + c)/(b + d) is…

By the theorem on equal ratios, (a + c)/(b + d) equals each of the equal ratios: 2/5.

2. If a/2 = b/3 = c/4, then (a + b + c)/b is…

Let each ratio be k: a = 2k, b = 3k, c = 4k. Then 9k ÷ 3k = 3.

3. The mean proportional of 4 and 16 is…

√(4 × 16) = √64 = 8.

4. If 3, x, 12 are in continued proportion (x positive), then x is…

x² = 3 × 12 = 36, so x = 6.
