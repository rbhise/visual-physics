Sets, lesson 1

Sets and How to Write Them

The days of the week, the factors of 18, the letters of your name: each is a collection where you can say for sure what belongs. In mathematics such a collection is called a set.

What is a set?

Set. A set is a collection of objects in which it is possible to decide clearly whether a given object belongs to the collection or not. Each object in a set is called an element (or member) of the set.

“The months that have 31 days” is a set: January belongs, June does not. “The tall students in my class” is not a set, because people can disagree about who is tall. A set must be well defined.

Sets are usually named with capital letters \(A, B, C, \ldots\) and elements with small letters. If \(a\) is an element of set \(A\), we write \(a \in A\) and read it “\(a\) belongs to \(A\)”. If \(b\) is not an element of \(A\), we write \(b \notin A\).

Two ways to write a set

Listing method (roster method). Write every element inside curly brackets \(\{\;\}\), separated by commas. Each element is written only once, and the order does not matter.

$$A = \{2, 4, 6, 8, 10, 12\}$$

Rule method (set-builder method). Write a general element, say \(x\), and after a vertical bar the property every element has. The bar “\(|\)” is read “such that”.

$$A = \{x \mid x \text{ is an even natural number}, x < 13\}$$

Some sets of numbers have their own letters: \(N\) natural numbers, \(W\) whole numbers, \(I\) integers, \(Q\) rational numbers and \(R\) real numbers.

Types of sets

TypeMeaningExample
Singleton setexactly one element\(\{x \mid x \in N, x^2 = 49\} = \{7\}\)
Empty (null) setno element at all; written \(\{\;\}\) or \(\varnothing\)even prime numbers greater than 2
Finite setthe elements can be counted to an end\(\{1, 2, 3, 6, 9, 18\}\)
Infinite setthe elements never come to an end\(\{5, 10, 15, 20, \ldots\}\)

The number of elements in a finite set \(A\) is written \(n(A)\). For \(A = \{1, 2, 3, 6, 9, 18\}\), \(n(A) = 6\). The empty set has \(n(\varnothing) = 0\).

Equal sets

Equal sets. If every element of set \(A\) is in set \(B\) and every element of \(B\) is in \(A\), then \(A\) and \(B\) are equal sets: \(A = B\).

The letters of the word “listen” and the letters of the word “silent” form the same set \(\{l, i, s, t, e, n\}\), so the two sets are equal. Order and repetition make no difference.

Worked examples

1. Rule form to listing form

Write \(A = \{x \mid x \text{ is a factor of } 18\}\) by the listing method and find \(n(A)\).

  1. The factors of 18 come in pairs: \(1 \times 18,\; 2 \times 9,\; 3 \times 6\).
  2. A = {1, 2, 3, 6, 9, 18} and n(A) = 6

2. Listing form to rule form

Write \(B = \{1, 4, 9, 16, 25\}\) by the rule method.

  1. Look for the pattern: \(1 = 1^2,\; 4 = 2^2,\; 9 = 3^2,\; 16 = 4^2,\; 25 = 5^2\).
  2. B = {x | x = n², n ∈ N, n ≤ 5}, or in words, “the squares of the first five natural numbers”.

3. Which type of set?

Say whether each set is empty, singleton, finite or infinite: (i) \(P = \{x \mid x \in N, x + 4 = 4\}\) (ii) \(Q = \{0\}\) (iii) \(S\) = the letters of the word “MISSISSIPPI” (iv) \(T = \{x \mid x \text{ is an odd natural number}\}\).

  1. (i) \(x + 4 = 4\) gives \(x = 0\), which is not a natural number: P = ∅, empty
  2. (ii) \(Q\) has one element, the number 0: singleton
  3. (iii) Write each letter once: \(S = \{M, I, S, P\}\): finite, n(S) = 4
  4. (iv) \(T = \{1, 3, 5, 7, \ldots\}\) never ends: infinite

Common mistakes

  • Writing an element twice. The letters of “banana” form the set {b, a, n}, not {b, a, n, a, n, a}.
  • Calling {0} empty. {0} has one element, the number 0, so it is a singleton set. The empty set is { } or ∅.
  • Thinking order matters. {1, 2, 3} and {3, 1, 2} have the same elements, so they are equal sets.
  • Collecting vague things. “Good singers” or “big cities” are not sets: there is no clear test of who belongs.

Quick check

1. Which of these is a set?

Only the months with 31 days can be decided without doubt: January, March, May, July, August, October and December.

2. A = {x | x is a prime number, 10 < x < 20}. What is n(A)?

A = {11, 13, 17, 19}, so n(A) = 4. 15 is not prime.

3. Which set is empty?

x + 3 = 3 gives x = 0, and 0 is not a natural number. {0} has one element; the even prime set is {2}; and {x | x ∈ N, x < 2} = {1}.

4. Which two sets are equal?

Both are {s, t, o, p}: the same four letters in a different order.
