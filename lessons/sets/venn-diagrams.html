Venn Diagrams, Subsets and Complements

A picture often says more than a list. Draw a set as a closed curve with its elements inside, and you can see at a glance which sets sit inside others and what is left outside.

Venn diagrams

A Venn diagram shows a set as a closed figure, such as a circle or an oval, with its elements written inside. The idea comes from the English mathematician John Venn. In the simulation, set \(A\) is the green circle and set \(B\) the orange circle.

Subsets

Subset. If every element of set \(B\) is also an element of set \(A\), then \(B\) is a subset of \(A\). We write \(B \subseteq A\) and read it “\(B\) is a subset of \(A\)”.

For \(A = \{1, 2, 3, 4, 6, 12\}\) (the factors of 12) and \(B = \{1, 2, 3, 6\}\) (the factors of 6), every element of \(B\) is in \(A\), so \(B \subseteq A\). In a Venn diagram the circle for \(B\) is drawn inside the circle for \(A\).

  • Every set is a subset of itself: \(A \subseteq A\).
  • The empty set is a subset of every set: \(\varnothing \subseteq A\).
  • If \(A \subseteq B\) and \(B \subseteq A\), then \(A = B\).
  • If \(A \subseteq B\) and \(B \subseteq C\), then \(A \subseteq C\). For example \(N \subseteq W \subseteq I\), so \(N \subseteq I\).

The universal set

When we work with some sets, we choose one big set that contains all of them. It is called the universal set, written \(U\), and is drawn as a rectangle. Every set in the discussion is a subset of \(U\). If we talk about the factors of 12 and the factors of 6, we might take \(U = \{1, 2, 3, \ldots, 12\}\).

Complement of a set

Complement. Let \(U\) be the universal set and \(A \subseteq U\). The set of all elements of \(U\) that are not in \(A\) is called the complement of \(A\), written \(A'\). $$A' = \{x \mid x \in U, \; x \notin A\}$$

In a Venn diagram, \(A'\) is the part of the rectangle outside circle \(A\). Some properties:

  • The complement of \(A'\) is \(A\) again: \((A')' = A\).
  • \(U' = \varnothing\) and \(\varnothing' = U\).
  • \(A\) and \(A'\) share no element, and together they make up \(U\), so \(n(A) + n(A') = n(U)\).

Try it

Choose what to shade with the chips. Drag any number into another region to change the sets; the readouts follow.

  • A subset. Factors of 6 inside factors of 12.
  • Not a subset. Even numbers and multiples of 3. Is B ⊆ A?
  • Make it a subset. Same sets: drag 3 and 9 out of B (or into the overlap). What changes?
  • Complement. U = {1, …, 10}, A = the prime numbers. Find A′.

What you should see: B = {1, 2, 3, 6} ⊆ A. For the even numbers and the multiples of 3, 3 ∈ B but 3 ∉ A, so B is not a subset; once 3 and 9 are moved, every element left in B is even and B ⊆ A. The primes up to 10 are {2, 3, 5, 7}, so A′ = {1, 4, 6, 8, 9, 10} and 4 + 6 = 10 = n(U).

Worked examples

1. Finding a complement

\(U = \{1, 2, 3, \ldots, 10\}\) and \(A = \{x \mid x \text{ is an odd number}, x \in U\}\). Find \(A'\) and check \(n(A) + n(A') = n(U)\).

  1. \(A = \{1, 3, 5, 7, 9\}\). Take the elements of \(U\) that are not in \(A\).
  2. A′ = {2, 4, 6, 8, 10}
  3. \(n(A) + n(A') = 5 + 5 = 10 = n(U)\) ✓

2. Is it a subset?

\(P = \{x \mid x \text{ is a multiple of } 4, x \le 20\}\) and \(Q = \{x \mid x \text{ is an even natural number}, x \le 20\}\). Is \(P \subseteq Q\)? Is \(Q \subseteq P\)?

  1. \(P = \{4, 8, 12, 16, 20\}\) and \(Q = \{2, 4, 6, \ldots, 20\}\).
  2. Every multiple of 4 is even, so every element of \(P\) is in \(Q\): P ⊆ Q
  3. \(2 \in Q\) but \(2 \notin P\): Q is not a subset of P

3. All the subsets

Write all the subsets of \(M = \{p, q\}\).

  1. No element: \(\varnothing\). One element: \(\{p\}, \{q\}\). Both elements: \(\{p, q\}\).
  2. ∅, {p}, {q}, {p, q}: 4 subsets in all. Do not forget \(\varnothing\) and \(M\) itself.

Common mistakes

  • Writing 2 ⊆ A. Use ∈ for an element and ⊆ for a set: 2 ∈ A, but {2} ⊆ A.
  • Reading B ⊆ A the wrong way. B ⊆ A means every element of B is in A. B is the one drawn inside.
  • Forgetting U. A′ depends on the universal set. With a different U the complement changes.
  • Missing subsets. ∅ and the set itself are always subsets. {p, q} has 4 subsets, not 2.

Quick check

1. U = {1, 2, 3, 4, 5, 6, 7, 8} and A = {2, 4, 6, 8}. A′ is…

A′ has the elements of U that are not in A: 1, 3, 5 and 7.

2. Which statement is true?

1 and 2 are both in {1, 2, 3}. 4 is not, {1, 2} lacks 3, and 3 is an element, so we write 3 ∈ {1, 2, 3}.

3. How many subsets does {x, y} have?

∅, {x}, {y} and {x, y}.

4. n(U) = 9 and n(A) = 4. Then n(A′) is…

n(A) + n(A′) = n(U), so n(A′) = 9 − 4 = 5.
