Linear Equations in Two Variables, lesson 2

Solving Simultaneous Equations

One equation has endless solutions. Add a second condition and usually only one pair of numbers satisfies both. Finding that pair is called solving simultaneous equations.

Download slides (.pptx) 12 slides with teacher notes

Two equations, one answer

A pair of linear equations in the same two variables, considered together, are called simultaneous equations. Their solution is the pair \((x, y)\) that satisfies both. On a graph, each equation is a line; the solution is the point where the lines cross.

Elimination method

Make the coefficients of one variable equal (multiply one or both equations if needed), then add or subtract the equations so that variable disappears. Solve for the other variable and substitute back.

$$\begin{aligned} x + y &= 4 &&\text{(I)}\\ 2x - 5y &= 1 &&\text{(II)} \end{aligned}$$

Multiply (I) by 5: \(5x + 5y = 20\). Add (II): \(7x = 21\), so \(x = 3\). Then from (I), \(y = 4 - 3 = 1\). The solution is \((3, 1)\).

Substitution method

Make one variable the subject of one equation, substitute that expression into the other equation, and solve. From (I), \(x = 4 - y\). Put it in (II): \(2(4 - y) - 5y = 1\), so \(8 - 7y = 1\), \(y = 1\) and \(x = 3\). Same answer.

Always check. Put your answer into both original equations. \((3, 1)\): \(3 + 1 = 4\) ✓ and \(6 - 5 = 1\) ✓.

When there is no single answer

If the two lines are parallel they never meet, and the equations have no solution. If both equations describe the same line, there are infinitely many. You can see both cases in the simulation.

Try it

Set the equations with the sliders, then press “Show the steps”.

  • Elimination. x + y = 4 and 2x − 5y = 1.
  • Substitution. The same pair by substitution.
  • Add to eliminate. 3x − 5y = −16 and 2x + 5y = 31.
  • Parallel lines. x + 2y = 4 and 2x + 4y = 12.

What you should see: both methods give (3, 1), and the lines cross there. In the third pair the y-terms already cancel when you add: 5x = 15, so x = 3 and y = 5. In the last pair the lines are parallel: there is no solution.

Worked examples

1. Elimination by adding

Solve \(3x - 5y = -16\) and \(2x + 5y = 31\).

  1. The y-coefficients are −5 and +5. Add the equations: \(5x = 15\), so \(x = 3\).
  2. Put \(x = 3\) in the second: \(6 + 5y = 31\), so \(5y = 25\), \(y = 5\).
  3. x = 3, y = 5

2. Multiply first

Solve \(2x + 3y = 12\) and \(3x - 2y = 5\).

  1. Multiply the first by 2 and the second by 3: \(4x + 6y = 24\), \(9x - 6y = 15\).
  2. Add: \(13x = 39\), so \(x = 3\). Then \(2(3) + 3y = 12\), so \(y = 2\).
  3. x = 3, y = 2

3. Substitution

Solve \(y = 2x - 1\) and \(3x + 2y = 12\).

  1. The first is already solved for y. Substitute: \(3x + 2(2x - 1) = 12\).
  2. \(7x - 2 = 12\), so \(x = 2\), and \(y = 2(2) - 1 = 3\).
  3. x = 2, y = 3

Common mistakes

  • Adding when you should subtract. If the coefficients have the same sign, subtract; if opposite signs, add.
  • Multiplying only one side. When you multiply an equation, multiply every term, including the right side.
  • Stopping after one variable. You need both x and y. Substitute back to find the second.
  • Skipping the check. Substitute into both original equations; a slip shows up at once.

Quick check

1. Solve x + y = 10 and x − y = 2.

Add: 2x = 12, x = 6, then y = 4.

2. To eliminate y from 2x + 3y = 7 and 5x − 3y = 14, you should…

+3y and −3y cancel when you add.

3. On a graph, the solution of two simultaneous equations is…

Only the crossing point lies on both lines.

4. x + 2y = 4 and 2x + 4y = 12 have…

The lines are parallel: the second has the same slope but a different constant.
