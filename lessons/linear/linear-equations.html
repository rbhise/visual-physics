Linear Equations in Two Variables

Two friends have 7 sweets between them. Rahul could have 1 and Sneha 6, or 3 and 4, or 5 and 2. One equation, many answers, and all of them sit on one straight line.

Equations with two unknowns

An equation such as \(x + y = 7\) has two variables, and each appears only to the power 1. It is a linear equation in two variables. Any such equation can be written in the general form

$$ax + by + c = 0$$

where \(a\), \(b\) and \(c\) are real numbers and \(a\) and \(b\) are not both zero. For example, \(3x - 4y = -12\) becomes \(3x - 4y + 12 = 0\).

Solutions

A solution is a pair of values, one for \(x\) and one for \(y\), that makes the equation true. We write it as an ordered pair \((x, y)\). To test a pair, substitute both values and see whether the two sides are equal.

  • \((2, 5)\) satisfies \(x + y = 7\) because \(2 + 5 = 7\).
  • \((3, 1)\) does not, because \(3 + 1 = 4 \ne 7\).

Pick any value for \(x\) and you can work out the matching \(y\). So a linear equation in two variables has infinitely many solutions.

The solutions form a line

Plot the solutions as points on a graph and something striking happens: they all lie on one straight line. Every point on that line is a solution, and every solution is a point on it. That is why these equations are called linear. The line crosses the x-axis where \(y = 0\) and the y-axis where \(x = 0\).

Try it

Drag the point on the grid, or use the point sliders.

  • Find solutions. Mark four points that satisfy x + y = 7.
  • Show the line. Do your marked points sit on it?
  • A new equation. Try 2x + 3y = 12.
  • Negative coefficient. x − y = 2: which way does the line slope?

What you should see: for x + y = 7 the pairs (0, 7), (1, 6), (2, 5), (3, 4) … all pass, and they lie on one line that crosses both axes at 7. For 2x + 3y = 12, (3, 2) works because 6 + 6 = 12; the line crosses the axes at (6, 0) and (0, 4). The line x − y = 2 slopes upwards.

Worked examples

1. General form

Write \(2x = 5y - 3\) in the form \(ax + by + c = 0\).

  1. Move every term to one side: \(2x - 5y + 3 = 0\)
  2. So \(a = 2\), \(b = -5\), \(c = 3\): 2x − 5y + 3 = 0

2. Is it a solution?

Which of \((3, 2)\) and \((1, 4)\) are solutions of \(2x + 3y = 12\)?

  1. \((3, 2)\): \(2(3) + 3(2) = 6 + 6 = 12\) ✓ solution
  2. \((1, 4)\): \(2(1) + 3(4) = 2 + 12 = 14 \ne 12\) not a solution

3. Finding solutions

Find three solutions of \(x - 2y = 4\).

  1. Make \(x\) the subject: \(x = 4 + 2y\).
  2. \(y = 0 \Rightarrow x = 4\); \(y = 1 \Rightarrow x = 6\); \(y = 2 \Rightarrow x = 8\)
  3. Three solutions: (4, 0), (6, 1), (8, 2)

Common mistakes

  • Writing the pair the wrong way round. (x, y) always means x first. (2, 5) and (5, 2) are different points.
  • “It has only one answer.” One linear equation in two variables has infinitely many solutions.
  • Testing only one side. Substitute into the left side and compare it with the right side.
  • Forgetting signs when rearranging. 2x = 5y − 3 becomes 2x − 5y + 3 = 0, not 2x + 5y − 3 = 0.

Quick check

1. Which of these is a linear equation in two variables?

Both variables appear only to the power 1 and are not multiplied together.

2. Which pair is a solution of x + 2y = 10?

4 + 2 × 3 = 10.

3. How many solutions does 3x + y = 9 have?

Every point on its line is a solution.

4. Where does the line x + y = 7 cross the y-axis?

On the y-axis x = 0, so y = 7.
