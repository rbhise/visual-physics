Irrational and Real Numbers

√2 never stops and never repeats, yet you can mark it exactly on a number line with a ruler and compass. Together, the rational and irrational numbers fill the whole line: the real numbers.

Irrational numbers

Irrational number. A number whose decimal form is non-terminating and non-recurring is called an irrational number. It cannot be written in the form \(\dfrac{p}{q}\).

Examples: \(\sqrt{2} = 1.41421356\ldots\), \(\sqrt{3} = 1.7320508\ldots\), \(\pi = 3.14159265\ldots\) The digits never end, and no block repeats. (\(\dfrac{22}{7}\) is only an approximate value of \(\pi\); it is rational.) If \(n\) is a positive integer that is not a perfect square, \(\sqrt{n}\) is irrational.

Why √2 is irrational (indirect proof). Suppose \(\sqrt{2} = \dfrac{p}{q}\) in lowest terms. Then \(p^2 = 2q^2\), so \(p^2\) is even and \(p\) is even, say \(p = 2m\). Then \(4m^2 = 2q^2\), so \(q^2 = 2m^2\) and \(q\) is even too. Both even contradicts “lowest terms”, so \(\sqrt{2}\) is not rational.

A rational number plus an irrational number is irrational, and a non-zero rational number times an irrational number is irrational. So \(5 + \sqrt{3}\) and \(4\sqrt{3}\) are irrational.

√2 on the number line

Mark O at 0 and A at 1. At A draw a perpendicular AB of length 1. By Pythagoras, \(OB^2 = 1^2 + 1^2 = 2\), so \(OB = \sqrt{2}\). With centre O and radius OB, draw an arc to cut the number line at P. Then \(OP = \sqrt{2}\): the point P is \(\sqrt{2}\).

For \(\sqrt{5}\) use legs 2 and 1, since \(2^2 + 1^2 = 5\). For \(\sqrt{3}\), stand a side of 1 on \(\sqrt{2}\): \((\sqrt{2})^2 + 1^2 = 3\). Repeating this gives the spiral of square roots.

Real numbers

Real numbers. The rational numbers and the irrational numbers together form the set of real numbers, \(R\). Every real number is shown by a unique point on the number line, and every point on the number line shows a unique real number.

So \(N \subset W \subset I \subset Q \subset R\): natural numbers, whole numbers, integers, rational numbers, real numbers. Between any two real numbers there are infinitely many rational numbers; for example 1.5, 1.6 and 1.7 lie between \(\sqrt{2} \approx 1.414\) and \(\sqrt{3} \approx 1.732\).

The square of a real number is never negative. So the square root of a negative number, such as \(\sqrt{-9}\), is not a real number.

Order properties of real numbers

For real numbers \(a\), \(b\), \(c\):

  • exactly one of \(a < b\), \(a = b\), \(a > b\) is true;
  • if \(a < b\) and \(b < c\), then \(a < c\);
  • if \(a < b\), then \(a + c < b + c\);
  • if \(a < b\) and \(c > 0\), then \(ac < bc\); but if \(c < 0\), then \(ac > bc\).

Absolute value

Absolute value. For a real number \(x\): \(|x| = x\) if \(x > 0\); \(|x| = 0\) if \(x = 0\); \(|x| = -x\) if \(x < 0\).

\(|x|\) is the distance of \(x\) from 0 on the number line, so it is never negative: \(|8| = 8\) and \(|-8| = -(-8) = 8\). In the same way, \(|x - a|\) is the distance between \(x\) and \(a\). So \(|x - a| = d\) (with \(d > 0\)) has two solutions, \(x = a + d\) and \(x = a - d\).

What you should see: √2 = 1.41421356…, between 1.41 and 1.42. √5 = 2.2360679…, from legs 2 and 1. √3 needs √2 first. In the spiral, √4 = 2, √9 = 3 and √16 = 4 are the only whole numbers. |−6| = 6. |x − 5| = 2 gives x = 3 or x = 7. Multiplying 2 < 5 by −2 gives −4 > −10: the order is reversed.

Worked examples

1. √5 on the number line

Show \(\sqrt{5}\) on the number line.

  1. \(5 = 2^2 + 1^2\). Mark O at 0 and A at 2.
  2. At A draw AB perpendicular to the line, with AB = 1. Then \(OB^2 = 2^2 + 1^2 = 5\), so \(OB = \sqrt{5}\).
  3. With centre O and radius OB, draw an arc cutting the line at P. OP = √5 ≈ 2.236

2. An absolute value equation

Solve \(|x + 2| = 3\).

  1. \(|x + 2| = |x - (-2)|\) is the distance between \(x\) and \(-2\).
  2. Go 3 each way from \(-2\): \(x + 2 = 3\) or \(x + 2 = -3\).
  3. x = 1 or x = −5

3. Rational numbers between two irrationals

Write three rational numbers between \(\sqrt{2}\) and \(\sqrt{3}\).

  1. \(\sqrt{2} = 1.414\ldots\) and \(\sqrt{3} = 1.732\ldots\)
  2. Any terminating decimal between them is rational: 1.5, 1.6, 1.7.
  3. \(\tfrac{3}{2}, \tfrac{8}{5}, \tfrac{17}{10}\) (and infinitely many more)

Common mistakes

  • Calling 22/7 or 3.14 “π”. They are rational approximations. π itself is irrational.
  • Thinking every square root is irrational. √49 = 7 and √0.25 = 0.5 are rational. Only roots of non-perfect squares are irrational.
  • Keeping the sign inside | |. |−8| = 8. An absolute value is a distance, so it is never negative.
  • Forgetting to flip the sign. If a < b and you multiply by a negative number, the order reverses: −3a > −3b.

Quick check

1. Which of these is irrational?

7 is not a perfect square, so √7 is non-terminating and non-recurring. The others can be written as p/q.

2. \(|-9| + |4| = \)…

|−9| = 9 and |4| = 4, so the sum is 13.

3. If \(a < b\), then \(-2a\) … \(-2b\).

Multiplying by a negative number reverses the order.

4. To show \(\sqrt{10}\) on the number line, a right triangle with legs … works.

3² + 1² = 9 + 1 = 10, so the hypotenuse is √10.
