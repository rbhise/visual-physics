Rational numbers

Rational number. A number of the form \(\dfrac{p}{q}\), where \(p\) and \(q\) are integers and \(q \neq 0\), is called a rational number. The set of rational numbers is written \(Q\).

Every integer is rational, because \(-4 = \dfrac{-4}{1}\). One rational number has many names: \(\dfrac{3}{4} = \dfrac{6}{8} = \dfrac{9}{12}\). The form with no common factor in \(p\) and \(q\) is its lowest terms (simplest form).

Properties of rational numbers

Let \(a\), \(b\), \(c\) be rational numbers. Then \(a + b\), \(a - b\) and \(a \times b\) are rational, and \(a \div b\) is rational when \(b \neq 0\).

PropertyAdditionMultiplication
Commutative\(a + b = b + a\)\(a \times b = b \times a\)
Associative\((a + b) + c = a + (b + c)\)\((a \times b) \times c = a \times (b \times c)\)
Identity\(a + 0 = a\)\(a \times 1 = a\)
Inverse\(a + (-a) = 0\)\(a \times \dfrac{1}{a} = 1\) if \(a \neq 0\)

Multiplication distributes over addition: \(a \times (b + c) = a \times b + a \times c\). For example, the additive inverse of \(\dfrac{2}{9}\) is \(-\dfrac{2}{9}\), and its multiplicative inverse (reciprocal) is \(\dfrac{9}{2}\).

Decimal form of a rational number

To write \(\dfrac{p}{q}\) as a decimal, divide \(p\) by \(q\). Two things can happen:

  • the remainder becomes 0 and the division stops: a terminating decimal, such as \(\dfrac{7}{8} = 0.875\);
  • the remainder never becomes 0 and a group of digits repeats for ever: a non-terminating recurring decimal, such as \(\dfrac{5}{6} = 0.8333\ldots\)

We write the repeating digits once, with a bar over them: \(0.8333\ldots = 0.8\overline{3}\) and \(0.272727\ldots = 0.\overline{27}\). (Some books put a dot over the repeating digit instead.)

Why the digits must repeat

When you divide by \(q\), every remainder is one of \(0, 1, 2, \ldots, q - 1\). There are only \(q\) of them, so within \(q\) steps either the remainder becomes 0 or a remainder comes back. Once a remainder comes back, the same digits follow again and again. The remainder wheel in the simulation shows this.

Rule. Write \(\dfrac{p}{q}\) in lowest terms. If the prime factors of \(q\) are only 2 and 5, the decimal form is terminating. If \(q\) has any other prime factor, it is non-terminating recurring.
So the decimal form of every rational number is either terminating or non-terminating recurring.

The reason: when \(q\) is made only of 2s and 5s, you can multiply top and bottom to get a power of 10. \(\dfrac{7}{8} = \dfrac{7 \times 125}{8 \times 125} = \dfrac{875}{1000} = 0.875\). No power of 10 is a multiple of 3 or 7, so \(\dfrac{1}{3}\) or \(\dfrac{2}{7}\) can never stop.

Recurring decimal to p/q

Call the decimal \(x\). Multiply by 10, 100, 1000, … so that the repeating tails line up, then subtract. The endless tails cancel.

$$\begin{aligned} x &= 0.4545\ldots \\ 100x &= 45.4545\ldots \\ 100x - x &= 45 \;\Rightarrow\; 99x = 45 \;\Rightarrow\; x = \tfrac{45}{99} = \tfrac{5}{11} \end{aligned}$$

Use 10 for a block of one digit, 100 for a block of two digits, and so on. If some digits come before the block, as in \(0.2\overline{7}\), first multiply by 10 to move them past the point: \(10x = 2.777\ldots\), \(100x = 27.777\ldots\), so \(90x = 25\) and \(x = \dfrac{25}{90} = \dfrac{5}{18}\).

  • 0.3636…. Turn it back into p/q.

What you should see: 1/6 gives remainders 1, 4, 4: the 4 comes back, so \(\tfrac16 = 0.1666\ldots = 0.1\overline{6}\). 7/8 = 0.875 stops, because the remainder reaches 0. 3/7 = 0.428571428571…: the block 428571 has 6 digits and uses every remainder from 1 to 6. 9/12 = 3/4 = 0.75. 0.3636… = 36/99 = 4/11, and 1.2454545… = 1233/990 = 137/110.

Worked examples

1. Decide without dividing

Which of \(\dfrac{13}{40}\), \(\dfrac{7}{30}\) and \(\dfrac{21}{28}\) have terminating decimal forms?

  1. \(40 = 2^3 \times 5\): only 2s and 5s, so \(\dfrac{13}{40}\) terminates. Indeed \(\dfrac{13}{40} = \dfrac{325}{1000} = 0.325\).
  2. \(30 = 2 \times 3 \times 5\) has the factor 3, so \(\dfrac{7}{30} = 0.2333\ldots = 0.2\overline{3}\) is non-terminating recurring.
  3. \(\dfrac{21}{28} = \dfrac{3}{4}\) in lowest terms, and \(4 = 2^2\). So it terminates: \(0.75\).
  4. 13/40 and 21/28 terminate; 7/30 recurs

2. A block of two digits

Write \(0.\overline{72}\) in the form \(\dfrac{p}{q}\).

  1. Let \(x = 0.7272\ldots\). The block has 2 digits, so multiply by 100: \(100x = 72.7272\ldots\)
  2. Subtract: \(100x - x = 72\), so \(99x = 72\).
  3. \(x = \dfrac{72}{99} = \) \(\dfrac{8}{11}\)

3. Digits before the block

Write \(0.58\overline{3}\) in the form \(\dfrac{p}{q}\).

  1. Let \(x = 0.58333\ldots\). Two digits come before the block: \(100x = 58.333\ldots\)
  2. One more place moves one block across: \(1000x = 583.333\ldots\)
  3. Subtract: \(1000x - 100x = 583 - 58\), so \(900x = 525\).
  4. \(x = \dfrac{525}{900} = \) \(\dfrac{7}{12}\)

Common mistakes

  • Using the denominator before cancelling. 21/28 looks like it should recur (28 = 2² × 7), but 21/28 = 3/4 terminates. Always write the fraction in lowest terms first.
  • Putting the bar in the wrong place. 0.1666… is \(0.1\overline{6}\), with the bar on the 6 only. \(0.\overline{16}\) would mean 0.161616…
  • Multiplying by 10 for every block. Use 10 for a 1-digit block, 100 for a 2-digit block, 1000 for a 3-digit block, so the tails line up.
  • Calling a long decimal irrational. 1/17 has a block of 16 digits, but it still repeats. Every p/q terminates or recurs.

Quick check

1. Which of these has a terminating decimal form?

40 = 2³ × 5 has no prime factor other than 2 and 5, so 9/40 = 0.225. The others have the factor 3.

2. \(0.\overline{4}\) written as \(\dfrac{p}{q}\) is…

x = 0.444…, 10x = 4.444…, so 9x = 4 and x = 4/9.

3. The decimal form of \(\dfrac{5}{11}\) is…

50 ÷ 11 = 4 remainder 6, 60 ÷ 11 = 5 remainder 5, and remainder 5 comes back: 0.454545…

4. \(\dfrac{2}{3} + \dfrac{1}{5} = \dfrac{1}{5} + \dfrac{2}{3}\) shows which property?

Changing the order of the numbers does not change the sum: the commutative property of addition.
